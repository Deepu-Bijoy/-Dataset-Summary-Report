# Dataset Summary Report

## Description
A simple Pandas notebook for loading and exploring a CSV dataset. It analyzes the dataset structure, data types, descriptive statistics, and missing values.

## Features
- View first and last rows
- Display random samples
- Check rows and columns
- View columns and index
- Check data types
- Use `info()` and `describe()`
- Check missing values
- Display basic dataset observations

## Requirements
- Python 3
- Pandas
- Google Colab or Jupyter Notebook

## How to Run
1. Open the notebook in Google Colab.
2. Upload the CSV dataset provided by the LMS.
3. Set the correct CSV filename in the notebook.
4. Run all cells.
